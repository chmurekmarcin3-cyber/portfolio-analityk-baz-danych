# Projekt 12 – Finanse Osobiste

## Opis projektu

Projekt przedstawia analizę finansów osobistych wykonaną w Power BI.

## Technologie

- Microsoft Excel
- Power BI

## Analizowane dane

- Data
- Typ transakcji
- Kategoria
- Kwota

## Dashboard zawiera

- Łączne przychody
- Łączne wydatki
- Strukturę wydatków
- Analizę finansów w czasie
- Tabelę danych
- Filtry
