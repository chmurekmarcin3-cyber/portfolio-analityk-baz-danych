# Projekt 13 – Budżet Domowy

## Opis projektu

Projekt przedstawia analizę wydatków domowych wykonaną w Microsoft Excel oraz Power BI.

## Technologie

- Microsoft Excel
- Power BI

## Analizowane dane

- Data
- Kategoria
- Kwota
- Typ wydatku

## Dashboard zawiera

- Łączne wydatki
- Wydatki stałe
- Wydatki zmienne
- Strukturę wydatków według kategorii
- Analizę wydatków w czasie
- Tabelę danych
- Interaktywne filtry
