# Projekt 16 – SQL Ecommerce Advanced

## Opis projektu

Zaawansowany projekt analizy danych e-commerce wykonany przy użyciu PostgreSQL, DBeaver oraz Power BI.

## Technologie

* PostgreSQL
* DBeaver
* Power BI
* SQL

## Zakres projektu

### Baza danych

Utworzono bazę danych zawierającą:

* customers
* products
* orders
* order_items

### SQL

W projekcie wykonano 20 zapytań SQL obejmujących:

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* INNER JOIN
* LEFT JOIN
* CASE WHEN
* CTE
* ROW_NUMBER()
* RANK()
* SUM() OVER()
* AVG() OVER()

### Dashboard Power BI

Dashboard zawiera:

* Liczbę klientów
* Liczbę zamówień
* Liczbę produktów
* Produkty według kategorii
* Udział kategorii produktów
* Zamówienia w czasie
* Tabelę klientów
* Filtry danych
