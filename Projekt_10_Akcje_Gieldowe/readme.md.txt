# Projekt 10 – Analiza Akcji Giełdowych

## Opis projektu

Projekt przedstawia analizę cen akcji wybranych spółek technologicznych.

Analizowane spółki:
- Apple
- Microsoft
- Nvidia

## Technologie

- Excel
- Power BI

## Dashboard

Dashboard zawiera:

- KPI dla maksymalnych cen akcji
- Wykres liniowy zmian cen
- Porównanie średnich wartości
- Tabelę danych
- Filtry dat
